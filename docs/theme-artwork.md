# Theme artwork provenance

All five artworks were generated specifically for PrimePlaner through built-in ImageGen
from the owner's approved mockups on 2026-09-11. No downloaded third-party photographs.
UI screens are not used as wallpaper; each asset contains only background artwork.
Android consumes WebP in drawable-nodpi, quality 82, one image behind the app content.
Original mockups remain review artifacts, not screenshot evidence of the running app.
