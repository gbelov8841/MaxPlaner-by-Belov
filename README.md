# MaxPlaner

MaxPlaner — стильный Android-планер с принципом **Today first**: задачи, календарь, привычки, фокус и прогресс собраны в одном спокойном интерфейсе.

## Что уже работает

- экран **Сегодня** с главным фокусом и коротким планом дня;
- быстрые задачи: создание, выполнение и удаление;
- привычки с отметкой за сегодня и подсчётом серии;
- календарь ближайших 7 дней;
- 25-минутный фокус-таймер;
- экран прогресса: выполнение задач, привычек, фокус-минуты и лучшая серия;
- локальное offline-first хранение данных на устройстве;
- светлая и тёмная Material 3 тема;
- нижняя навигация: Сегодня / Календарь / Задачи / Привычки / Прогресс.

## Продуктовые принципы

- **Today-first** — сначала понятный сегодняшний день, а не бесконечный список.
- **Capture fast** — добавить дело можно за секунды.
- **Calm productivity** — минимум визуального шума.
- **Progress, not pressure** — статистика мотивирует, но не наказывает.
- **Offline-first** — основные функции работают без аккаунта и интернета.
- **Manual control first** — автоматизация помогает, но не забирает контроль у пользователя.

## Дизайн-направление

Визуальная система строится на глубоком зелёном, кремовых и песочных оттенках, крупных читаемых заголовках, округлых карточках, ясной иерархии и минимуме декоративного шума.

## Вдохновение

- Todoist — быстрый ввод, приоритеты и ясность задач.
- TickTick — привычки, Pomodoro, календарь и статистика.
- Sunsama — осознанное планирование дня и timeboxing.
- Structured — визуально лёгкая лента дня.
- Motion — будущий интеллектуальный слой автопланирования без потери ручного контроля.

## Сборка APK

GitHub Actions workflow `.github/workflows/android.yml` собирает debug APK и публикует его как артефакт **MaxPlaner-debug**.
